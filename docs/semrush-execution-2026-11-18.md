## Implementation decisions
- Preserve the three existing customization URLs as primary commercial landing pages. No thin keyword duplicates.
- Replace generic technical quick-answer openings with concise supplier answers naming TONTON, intended B2B buyers, customizable scope and project-specific minimum/sample conditions. Keep adjacent evidence and product references.
- Give each commercial quick-answer CTA its correct preselected product rather than a generic Rash Guard default.
- Add a free size/quantity planner to the existing size-planning resource: independent top/short allocations, exact totals, CSV export, copy brief and validated carry-through into Project Builder. Do not recommend a size ratio or pretend the placeholders are an approved measurement chart.
- Link this tool from the three customization answers and the resource hub.
- Analytics uses existing optional GA4 configuration; events count interactions, not qualified inquiries. GA4 receipt has not been verified in this release.
